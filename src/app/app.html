02

ONE-WAY · COMPONENT → VIEW

Interpolation

Displays component values as text using {{ expression }}.

app.ts + app.html{{ }}
studentName = 'Nimal';
completedLessons = 3;
totalLessons = 9;

<h3>Hello {{ studentName }}</h3>
<p>{{ completedLessons }} / {{ totalLessons }}</p>
<p>Remaining: {{ totalLessons - completedLessons }}</p>
LIVE RESULT

Hello {{ studentName }}

You are learning {{ courseTitle }}.

{{ completedLessons }} / {{ totalLessons }}lessons completed

Remaining: {{ totalLessons - completedLessons }}

Ask the student: If completedLessons becomes 5, which parts of the view will change?

03

ONE-WAY · COMPONENT → VIEW

Property binding

Assigns a TypeScript expression to a DOM property using [property]="expression".

Property binding[ ]
logoUrl = 'favicon.ico';
isSaveDisabled = false;

<img [src]="logoUrl" [alt]="logoDescription">
<button [disabled]="isSaveDisabled">Save</button>
LIVE RESULT

disabled = {{ isSaveDisabled }}

Key point: [disabled]="false" passes a boolean. disabled="false" still places the HTML attribute on the button.

ONE-WAY · COMPONENT → VIEW

Style binding

Changes an inline style with [style.property], including units such as .px and .percent.

Style bindingstyle.
headingColor = '#5b21b6';
headingSize = 28;
progressPercentage = 64;

<h3 [style.color]="headingColor"
    [style.font-size.px]="headingSize">Progress</h3>
<div [style.width.%]="progressPercentage"></div>
LIVE RESULT

Course progress

06

ONE-WAY · COMPONENT → VIEW

Class binding

Adds or removes a CSS class according to a boolean expression.

Class bindingclass.
isActiveStudent = true;
hasValidationError = false;

<div [class.active]="isActiveStudent"
     [class.invalid]="hasValidationError">
  Student status
</div>
LIVE RESULT
{{ isActiveStudent ? 'Active student' : 'Inactive student' }}{{ hasValidationError ? 'Validation requires attention' : 'Details are valid' }}

ONE-WAY · VIEW → COMPONENT

Event binding

Listens to browser events and runs a component expression using (event)="expression".

Event binding( )
clickCount = 0;

increaseCount(): void {
  this.clickCount++;
}

<button (click)="increaseCount()">Click</button>
LIVE RESULT
{{ clickCount }}click events handled

08

EVENT DETAILS

$event and key modifiers

$event gives the method the browser event object. Key modifiers filter keyboard events in the template.

$event + Enter$event
updateFromEvent(event: Event): void {
  const input = event.target as HTMLInputElement;
  this.eventInputValue = input.value;
}

<input (input)="updateFromEvent($event)"
       (keyup.enter)="submitWithEnter()">
LIVE RESULT

Value read from $event: {{ eventInputValue || '—' }}

{{ eventMessage }}

Try next: Replace keyup.enter with keyup.escape, or test a combination such as keydown.shift.enter.

10

COMPONENT ⇄ VIEW

Two-way binding

Keeps component state and a form control synchronized using [(ngModel)]. A standalone component must import FormsModule.

[(ngModel)]="formName"=[ngModel]="formName"+(ngModelChange)="formName = $event"
Two-way binding[()]
import { FormsModule } from '@angular/forms';

@Component({ imports: [FormsModule] })
export class App {
  formName = 'Nimal Perera';
}

<input [(ngModel)]="formName">
<p>{{ formName }}</p>
LIVE RESULT
LIVE COMPONENT STATE{{ formName }}{{ email }}{{ selectedCourse }} · terms: {{ acceptedTerms }}

Ask the student: What changes first when the user types—the input or the component property? Explain how both remain synchronized.

FINAL PRACTICE

Build a student registration card

Let the student combine every binding technique in one small feature.

  1. Display a title and lesson count with interpolation.
  2. Disable Submit until the form is valid with property binding.
  3. Add an accessible label with attribute binding.
  4. Show progress using style binding.
  5. Add valid and invalid states using class binding.
  6. Handle Submit and keyboard actions using event binding.
  7. Read one element with a template variable.
  8. Synchronize the form using [(ngModel)].
